## Research questions and hypotheses

| ID | Hypothesis | Test | Key metric |
|----|-----------|------|-----------|
| H1 | Richer countries win more medals *per person* | Spearman ρ | GDP per capita × medals per million |
| H2 | Larger countries win more medals *in absolute terms* | Spearman ρ | Population × total medals |
| H3 | Host countries outperform their own non-host baseline | Wilcoxon signed-rank (one-sided) | Host rate vs. typical non-host median |
| H4 | Medal rate differs systematically across income quartiles | Kruskal-Wallis H | Medals per million across Q1–Q4 |

## Integration pipeline explained

```
athlete_events.csv  (271 116 rows)
  │
  ├─ filter: Year ≥ 1960, Medal is not NaN  → 28 400 athlete-medal rows
  │
  ├─ DEDUPLICATION: drop_duplicates([Games, NOC, Event, Medal])
  │   → 13 616 unique medals  (team events counted once per NOC, not per athlete)
  │
  ├─ groupby [Year, Season, Games, NOC] → medal_counts (1 NOC × Games row)
  │
  ├─ LEFT JOIN noc_regions on NOC
  │   → ISO3 derived via (in priority order):
  │       1. WDI country-name normalised match  ("unitedstates" → USA)
  │       2. Documented alias table             (IVB → VGB, SKN → KNA …)
  │       3. NOC direct if already valid ISO3
  │       4. Historical sensitivity mapping     (URS→RUS, GDR→DEU, FRG→DEU, EUN→RUS, YUG→SRB, TCH→CZE, SCG→SRB)
  │       — 6 NOCs remain unmatched (saved to unmatched_nocs.csv for audit)
  │
  └─ LEFT JOIN WDI macro on (ISO3, Year)
      → gdp_per_capita_usd, population
      → rows missing either WDI field dropped → 1 095-row analytical sample
```

The row counts at each step are saved in `data/processed/join_audit.csv`.

## Key design decisions

### Team-medal deduplication
The raw `athlete_events.csv` has one row per *athlete*, so a 4×100 m relay team contributes 4 rows with `Medal = Gold`. Without deduplication this inflates medal counts by squad size. We apply:

```python
medals = athletes.loc[athletes.Medal.notna()].drop_duplicates(['Games', 'NOC', 'Event', 'Medal'])
```

This reduces 28 400 athlete-level medal rows to 13 616 distinct medal events — a 52 % reduction — before any aggregation.

### Historical NOC mapping
Defunct federations (URS, GDR, etc.) have no WDI data under their original codes. We map them to their modern successor states *only* as a **sensitivity mapping**, clearly labelled in the `mapping_source` column of the crosswalk. This is not a silent recoding: the raw files are untouched.

| Historical NOC | Mapped to | Successor rationale |
|---------------|-----------|---------------------|
| URS (USSR) | RUS | Russian Federation is the primary successor for WDI |
| GDR (East Germany) | DEU | Reunified Germany |
| FRG (West Germany) | DEU | Reunified Germany |
| EUN (Unified Team, 1992) | RUS | Largest successor state |
| YUG (Yugoslavia) | SRB | Serbia holds successor status in many international bodies |
| TCH (Czechoslovakia) | CZE | Successor by convention in sports statistics |
| SCG (Serbia & Montenegro) | SRB | Dissolved 2006 |

### Why non-parametric tests?
`medals_per_million` is strongly right-skewed (most countries win a handful; a few small, wealthy nations win many per person). Spearman ρ and Kruskal-Wallis are rank-based and require no normality assumption, making them appropriate for this distribution.

### Year range: 1960–2016
Pre-1960 WDI coverage is sparse for many nations. Limiting to 1960+ maximises WDI match rate while still covering 15 Summer and 14 Winter Games.

## Statistical results summary

> Results are descriptive / observational. No causal claim is made.

| Hypothesis | Statistic | p-value | Conclusion |
|-----------|-----------|---------|------------|
| H1: GDP per capita → medals/million | Spearman ρ = 0.370 | 7.1 × 10⁻³⁷ | Strong positive association; wealthier countries win more per person |
| H2: Population → total medals | Spearman ρ = 0.327 | 1.2 × 10⁻²⁸ | Moderate positive association; more populous countries win more in total |
| H3: Host country advantage | Wilcoxon W = 144, n = 17 pairs | 0.0003 | Host editions significantly above each country's own non-host baseline |
| H4: Income quartile differences | Kruskal-Wallis H = 138.9 | 6.6 × 10⁻³⁰ | Highly significant monotone increase from Q1 → Q4 |

**Log-linear OLS model** (log medals ~ log GDP/cap + log population):  
R² = 0.290, n = 1 095 — GDP per capita and population together explain ~29 % of the variance in log-medal count.

**PCA** (5 features: log GDP/cap, log population, medals/million, gold share, host flag):  
4 components needed to explain 87 % of variance, indicating the feature set captures several independent dimensions of Olympic success.

## Known limitations

- **Causality**: GDP, population, and host status are observational covariates — we cannot claim they *cause* medal success. Training infrastructure, sports culture, and government investment are confounders not modelled here.
- **Historical NOC mapping**: Mapping URS → RUS, etc. attributes Soviet-era medals to modern Russia's GDP/population. Results for these entries should be interpreted with caution.
- **WDI coverage**: 109 / 1 204 country-edition rows (pre-filter) lack GDP data, mostly for small island nations and pre-1980 years. These are dropped from the analytical sample.
- **Year range 1960–2016**: The 2020 Tokyo Games and 2022 Beijing Games are not in the Kaggle dataset.
- **Winter vs Summer**: Both are pooled. Per-capita medal rates differ substantially between games types; a robustness check splitting by season is advisable.
